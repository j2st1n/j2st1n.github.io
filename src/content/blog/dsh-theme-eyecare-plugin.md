这几天高强度泡在 DeepSeek Harness 的 Web 界面里写代码和改文档，一天下来盯屏幕七八个小时。

DSH 原生的界面做得很干净，但是白天用浅色模式时，大面积的纯白底色在自然光下看久了眼睛容易发酸。如果直接切到深色模式，纯黑底色加上高对比度的亮色文字，在白天的室内又显得太沉太冷硬。

我平时看书习惯用多看或者微信读书里的羊皮纸和绿豆沙底色，柔和且不刺眼。既然 DSH 底层基于 Cordis 插件体系，界面组件和 CSS 变量全都能动态扩展，我就索性让AI自己写了一个主题调色板插件，取名 `dsh-theme-eyecare`。
![DSH 护眼调色板插件效果预览](https://img.bins.blog/2026/08/uploads/dsh-theme-eyecare-preview---a8631914.png)

## 做了些什么

写这个插件时主要解决几个小细节。

第一个是明暗模式的独立叠加。我不想为了加一套绿色或者米黄色就把官方原生的浅色和深色切换给覆盖掉。插件里的每套色调都做了双维度自适应。浅色模式下，豆沙绿会把刺眼的亮白底色换成柔和的淡绿浅底，文字降成深墨绿。深色模式下，它会把纯黑背景换成极低刺激的暗夜墨绿，字调成柔灰白。羊皮纸和远峰蓝灰也是同样的思路。

第二个是界面的视觉一致。只改页面的主要背景色很容易留下色块漏洞。比如对话流里的用户提问气泡，还有输入框区域，如果不单独去覆盖相关的 CSS 变量，就会在绿底或米黄底上突兀地露出一大块默认的白底。我在插件里顺带把行内代码标签的背景色和边框都重新配了一遍，代码块嵌入在段落里时看起来很顺眼。

第三个是设置面板的嵌入方式。DSH 提供了标准的设置扩展槽位。通过在通用设置里注册一条项目，插件直接在官方外观选项正下方生成了一个护眼色调选择器，带双色小球微缩预览，选哪个就即时写入本地存储并切换样式。

## 怎么安装

插件代码已经推到了 GitHub，没有多余的依赖，直接在终端里用 DSH 的插件命令就能拉下来。

```sh
dsh plugin --profile web add github:j2st1n/dsh-theme-eyecare
```

安装完成后刷新或者重启一次 Web 界面，点开左下角设置里的通用选项，在外观下方就能看到护眼色调的几个卡片。

想临时换回官方原版风格时，点一下默认原色就能完全恢复。

代码开源在 [j2st1n/dsh-theme-eyecare](https://github.com/j2st1n/dsh-theme-eyecare)，平时也重度用 DSH 的朋友可以装上试试。
